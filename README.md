## 📚 학습 방법

- **주 2-3문제** 목표로 꾸준히 진행
- 15분 고민 후 아이디어가 안 떠오르면 힌트 확인
- 풀이를 본 문제는 3일 후 다시 풀어보기
- 각 알고리즘당 최소 3-5문제를 풀어 패턴 익히기
